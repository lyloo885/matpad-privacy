# MatPad — préparation du domaine

La vitrine reste locale. Aucun push ni changement DNS n’a été effectué.

Nom envisagé : matpad.lscinformatique.fr.
Dépôt existant : git@github.com:lyloo885/matpad-privacy.git.

L’hébergement actuel et le fournisseur DNS restent à confirmer. Si le site est bien hébergé sur GitHub Pages avec ce compte, l’enregistrement attendu sera un CNAME « matpad » vers « lyloo885.github.io ». Cette valeur est une proposition conditionnelle, pas une configuration vérifiée ou appliquée.

Il faut ajouter un enregistrement dans la zone DNS existante lscinformatique.fr ; une nouvelle zone indépendante n’est généralement pas nécessaire pour ce sous-domaine. Lors de la publication, configurer également le domaine personnalisé dans l’hébergement, vérifier sa propriété et activer HTTPS. Ne pas changer le DNS avant d’avoir vérifié la destination et préparé l’hébergement.

La politique de confidentialité d’origine est conservée dans confidentialite.html. Si une ancienne URL publique pointait sur la racine, mettre à jour les liens qui la référencent lors du lancement de la vitrine.

Aucun lien App Store n’a été ajouté faute d’adresse fournie. Les interfaces de la vitrine sont des illustrations HTML/CSS. L’affiche originale reste disponible dans assets/matpad-affiche.png.
