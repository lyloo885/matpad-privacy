Politique de confidentialité

Dernière mise à jour : 21 août 2026

Cette politique décrit le traitement des informations dans MatPad, application éducative native pour iPad. Elle concerne uniquement l’application, telle qu’elle est fournie sur iPad.

Présentation

MatPad est une application éducative native pour iPad. Elle permet notamment de travailler avec des opérations mathématiques, des tableaux et des outils associés.

Éditeur et responsable du traitement

L’éditeur et responsable du traitement est LSC Informatique.

Contact : contact@lscinformatique.fr

Données

MatPad :

  • ne nécessite aucun compte utilisateur ;
  • ne collecte aucun nom ;
  • ne collecte aucune adresse e-mail ;
  • ne collecte aucune localisation ;
  • ne collecte pas les contacts ;
  • ne collecte pas les photos ;
  • ne collecte aucun identifiant publicitaire ;
  • ne réalise aucun tracking.

Les nombres saisis dans les opérations mathématiques et les textes saisis dans les tableaux sont traités uniquement localement sur l’iPad.

Le texte libre peut contenir une information personnelle si l’utilisateur choisit lui-même d’en saisir une, par exemple un nom. MatPad ne collecte ni n’analyse cette information.

Stockage

Les données de travail sont conservées uniquement en mémoire pendant l’utilisation.

MatPad n’utilise pas de stockage persistant pour ces contenus :

  • pas de compte ;
  • pas de base de données distante ;
  • pas d’iCloud ;
  • pas de Core Data / SwiftData ;
  • pas de Keychain pour ces données ;
  • pas de stockage serveur.

Réseau

MatPad n’effectue aucun appel réseau pour transmettre les données saisies.

Aucune donnée utilisateur n’est envoyée aux serveurs de LSC Informatique.

Analytics, publicité et suivi

MatPad n’utilise :

  • aucun SDK publicitaire ;
  • aucun service d’analytics ;
  • aucun système de suivi utilisateur ;
  • aucun identifiant publicitaire ;
  • aucun cookie.

Permissions

MatPad ne demande pas d’accès :

  • à la caméra ;
  • au microphone ;
  • à la localisation ;
  • aux contacts ;
  • au suivi publicitaire.

Export PDF et JPG

MatPad permet à l’utilisateur de créer volontairement des exports JPG ou PDF.

Le fichier est créé localement dans un emplacement temporaire, puis la feuille de partage standard d’iPadOS est affichée.

Aucune transmission n’a lieu automatiquement.

Une donnée quitte éventuellement l’appareil uniquement lorsque l’utilisateur choisit volontairement une destination via la feuille de partage iPadOS, par exemple Fichiers, Mail ou une autre application.

LSC Informatique ne reçoit pas automatiquement ces fichiers.

Enfants

MatPad est une application éducative susceptible d’être utilisée par des enfants.

L’application ne demande pas leur identité et ne collecte volontairement aucune donnée personnelle concernant les enfants.

Suppression

Comme les données de travail ne sont pas envoyées à LSC Informatique et ne sont pas stockées sur un serveur, LSC Informatique ne possède pas de base de données utilisateur à supprimer.

Les données de travail locales disparaissent lorsqu’elles sont effacées ou lorsque leur conservation temporaire par l’application prend fin.

Contact

Pour toute question concernant la confidentialité :

contact@lscinformatique.fr
